## Codex Intercall Memory
- Added mainline BSD applet `fold`.
- Added mainline BSD applet `paste`.
- Updated `applets/mainline/cat` to implement BSD cat flags (-b/-e/-n/-s/-t/-u/-v) with line numbering and robust I/O/error handling.
- Updated `applets/mainline/echo` and `applets/go/echo` to match BSD echo behavior (only leading `-n`, escape processing by default, `\c` stop handling, robust writes).

- Updated mainline true/false to ignore arguments and return BSD-compatible exit codes.
- Updated mainline and TinyGo sleep to BSD semantics (single seconds operand, BSD-style errors, safe time_t conversion).
- Updated `applets/mainline/head` to match BSD head options (-n/-c/-q/-v and legacy -N), headers, and I/O/error handling.
- Added mainline BSD applets `basename`, `dirname`, `rmdir`, and `unlink`.
- Added mainline BSD applets `wc` and `yes`.
- Reworked `applets/mainline/tail` to implement BSD tail option parsing (legacy counts, -n/-c, -q/-v, -f/-F, -r), safe binary line/byte handling, and follow-mode behavior with robust I/O.
- Updated `applets/mainline/pwd` to validate `PWD` against the current directory and handle long paths via dynamic getcwd buffers.
- Added mainline BSD applets `cmp` and `comm`.
- Updated mainline and Go `uname` to BSD-style options/output ordering, removed GNU-only flags, and aligned nodename/arch/version outputs for cross-distribution parity.
- Updated mainline and Zig `tee` to BSD-compatible option parsing (-a/-i), signal handling, output file semantics, and robust read/write error handling.
- Updated mainline and Rust `mkdir` to match BSD option parsing, symbolic mode handling, and -p directory creation semantics with correct errors and permissions.
- Updated `applets/mainline/rm` to use `lstat` so symlinks are removed directly (no recursive traversal), and to avoid prompting for non-existent paths.
- Added mainline BSD applets `printenv` and `rev`.
- Added mainline BSD applet `printf`.
- Hardened `applets/mainline/printf` width/precision parsing to avoid signed overflow UB on large format widths.
- Updated mainline and Zig `cut` to enforce BSD option rules (-b/-c/-f exclusivity, -d/-s/-n validation), improve range parsing and error reporting, and fix field output for unterminated lines with robust I/O handling.
- Updated `applets/mainline/touch` to implement BSD touch option parsing (-A/-a/-c/-f/-h/-m/-r/-t), time parsing, and robust timestamp updates with correct creation semantics.
- Updated `applets/mainline/env` to implement BSD env option parsing (-i/-u/-P/-S/-v), argument splitting for -S, environment clearing, and exec path search with robust error handling.
- Updated Go `pwd` to match BSD/mainline behavior by validating $PWD with stat, honoring -L/-P, handling long paths, and reporting too many arguments.
- Reworked `applets/mainline/ln` to remove GNU options, implement BSD-style option parsing, hard/symbolic link creation, overwrite prompting, and directory handling with recursive -F removal.
- Fixed `applets/mainline/ln` directory cleanup to detect and report `readdir` errors during -F recursive removals instead of silently continuing to `rmdir`.
- Updated `applets/mainline/paste` to parse BSD-style delimiter escapes (including `\\n`, `\\t`, `\\0`, and `\\\\`) and handle NUL delimiters safely.
- Updated Zig `cat` to track numbering/blank-line state across files, add buffered output with -u support, and report BSD-style read/write errors.
- Added mainline BSD applet `cksum`.
- Updated `applets/mainline/kill` to allow BSD-style pid targeting (including 0/negative), expand signal name handling, and tighten list-mode parsing.
- Updated Zig `head` to mirror BSD/mainline option parsing, header handling, and error reporting with robust I/O.
- Updated clear across mainline/Rust/Zig/Go to use BSD-style options (-T/-V/-x), terminal capability checks, and consistent error handling.
- Reworked mainline `tr` to remove GNU-only flags, add BSD/POSIX-style option parsing, and implement full set expansion (classes, ranges, escapes, repeat), translation/deletion/squeeze logic with robust I/O.
- Fixed mainline `df` directory traversal to avoid following symlink cycles (preventing unbounded recursion/stack overflow) by switching to `lstat` and treating symlinks as leaf nodes.
- Hardened `applets/mainline/cp` I/O loops against EINTR/short writes and propagated close errors consistently.
- Fixed `applets/mainline/cp` path concatenation to avoid size_t overflow/heap overwrite on long paths and to report `readdir` failures reliably.
- Hardened `applets/mainline/hexdump` stdout writes to handle EINTR/short writes and report stdout errors.
- Fixed mainline `du` to avoid symlink-following recursion (stack overflow) by using `lstat`, added path length overflow checks, and reported `readdir` errors.
- Fixed `applets/mainline/df` `join_path` size_t overflow that could under-allocate and OOB-write on very long path components. Cause: unchecked size_t addition when combining `dir`/`name`. Fix: explicit overflow checks and `ENAMETOOLONG` on overflow.
- Fixed mainline `sort` buffer growth overflow that could wrap sizes and lead to heap overwrite on extremely long input lines or large line counts. Cause: unchecked size_t doubling during realloc for line buffers and pointer arrays. Fix: centralized growth helper with overflow guards and consistent `ENOMEM` handling, plus EINTR-safe I/O and zero-write detection to avoid hangs.
- Fixed mainline `sort` line assembly overflow that could wrap `len + 2` and lead to OOB writes on extremely long lines. Cause: missing size_t wrap guard before growing and writing line buffers. Fix: detect `SIZE_MAX - 2` overflow and return `EOVERFLOW` before realloc/write.
- Fixed mainline `ls` name list growth overflow that could wrap allocation size on extremely large directories and lead to OOB writes or crashes. Cause: unchecked `cap * 2` growth and multiplication by `sizeof(*names)`. Fix: guarded growth against `SIZE_MAX` overflow and report `out of memory`.
- Fixed mainline `ls` symlink handling to avoid following directory symlinks by default (BSD behavior) while still honoring trailing slash paths. Cause: `stat` used unconditionally, which dereferenced symlinks and could list unexpected directories. Fix: use `lstat` unless the path ends with `/`, matching FreeBSD `ls(1)`.
- Fixed mainline `ls` path assembly overflow that could under-allocate and OOB-write when combining extremely long directory and entry names. Cause: unchecked size_t addition when computing the `"/"` and NUL padding. Fix: guard the extra-length addition before allocating and return `ENAMETOOLONG` on overflow.
- Hardened mainline `mv` against symlink traversal and path overflow. Cause: `stat`/recursive delete followed symlinks, and `join_path` could overflow on long paths. Fix: use `lstat`, move symlinks via readlink/symlink, add `readdir` error checks, guard size_t arithmetic, and make I/O EINTR/zero-write safe.
- Fixed mainline `du` path assembly and size rounding overflows that could lead to OOB writes or signed overflow UB on very long path components or huge file sizes. Cause: unchecked `size_t` additions in `join_path` and `(size + 1023)` signed overflow in `blocks_1k`. Fix: explicit overflow guards with `ENAMETOOLONG`, and 1 KiB block rounding via division/modulo with clamping.
- Fixed mainline `yes` line construction overflow that could wrap `len + 1` and lead to `malloc(0)` followed by OOB writes on extremely large argument sizes. Cause: missing guard for the NUL terminator allocation. Fix: explicit `SIZE_MAX - 1` check returning `EOVERFLOW`.
- Fixed mainline `rm` path concatenation overflow that could under-allocate and OOB-write on very long directory/entry names. Cause: unchecked `size_t` addition in `join_path`. Fix: explicit overflow guard returning `ENAMETOOLONG`.
- Fixed mainline `vi` status buffer overflows that could corrupt memory or crash on long status messages. Cause: unbounded `vsprintf`/`sprintf` into a fixed 200-byte buffer. Fix: use `vsnprintf`/`snprintf` with explicit truncation and safe standout prefix/suffix handling.
- Fixed mainline `vi` command queue formatting and optimized cursor motion buffer overflows that could corrupt memory on large command counts or wide terminals. Cause: unbounded `sprintf` into `last_modifying_cmd` and unchecked `strcat`/`strncat` into `cm2`. Fix: `snprintf` with truncation fallback, plus explicit length guards and safe appends in `place_cursor`.
- Fixed mainline `vi` `memrchr` UB on reverse scans that could walk one byte before the buffer start. Cause: pointer-decrement loop compared pointers outside the object, invoking undefined behavior. Fix: iterate with a size_t index and check `p[i - 1]` while `i > 0`.
- Updated mainline `date` to handle empty `+` formats without error, grow the `strftime` buffer defensively, and report stdout errors consistently (FreeBSD date(1) behavior).
- Fixed mainline `xxd` line assembly overflow that could OOB-write on large `-c` column counts. Cause: `snprintf` return values advanced past a 512-byte stack buffer. Fix: compute required line capacity, allocate dynamically, and append with overflow checks plus robust stdout writes.
- Fixed mainline `comm` and `paste` line buffer growth overflow that could wrap `size_t` and under-allocate on extremely long lines, leading to OOB writes or crashes. Cause: unchecked `line->len + chunk + 1`/`line->len + 1` arithmetic before realloc. Fix: explicit overflow guards returning `EOVERFLOW`.
- Fixed mainline `rm` directory traversal to detect `readdir` errors and report them instead of silently continuing to `rmdir`. Cause: missing `errno` check after `readdir`, which masked directory I/O failures and could emit misleading errors. Fix: capture `errno`, report via existing `rm: path: error` format, and skip `rmdir` on failure.
- Fixed mainline `vi` status literal rendering overflow that could corrupt memory on long unprintable sequences. Cause: `print_literal` used unbounded `strcat` into a fixed `MAX_INPUT_LEN` buffer with late length checks. Fix: bounded appends with explicit buffer size tracking and truncation.
- Fixed mainline `vi` colon input buffer overflow when the command line hit `MAX_INPUT_LEN`, which could write the NUL terminator past `cmd`/`args`/`get_input_line__buf` and crash. Cause: buffers sized to `MAX_INPUT_LEN` without space for the terminator. Fix: allocate `MAX_INPUT_LEN + 1` for input command buffers.
- Fixed mainline `xxd` option parsing and skip handling to avoid `atoi` overflow UB, handle `EINTR` safely, and allow skip requests beyond EOF without spurious errors. Cause: unchecked `atoi` on `-g`/`-c`, non-retry `read`, and treating short reads during skip as hard failures. Fix: safe `strtol` parsing with fallbacks, EINTR-safe reads, and EOF-tolerant skipping for non-seekable inputs.
- Fixed mainline `dd` skip/seek handling to respect non-seekable inputs/outputs while surfacing real `lseek` errors, and to treat EOF during input skipping as a normal stop. Cause: ignored non-`ESPIPE`/`EINVAL` `lseek` failures and converted EOF during skip into `EIO`, yielding incorrect error exits. Fix: return errors on real `lseek` failures and stop skipping cleanly at EOF.
- Fixed mainline `cut` line buffering overflow that could wrap `len + 1` and lead to OOB writes on extremely long unterminated lines. Cause: unchecked size_t increment during field buffering. Fix: guard `len == SIZE_MAX`, use a checked `needed` size, and report `EOVERFLOW` before realloc/write.
- Fixed mainline `paste` delimiter parsing overflow that could OOB-write when `-d` uses unknown escape sequences that expand to multiple bytes. Cause: delimiter buffer allocated to `strlen(spec)` without growth while appending `\\` + char pairs. Fix: add bounded growth helper with overflow checks and ensure capacity before each append.
- Fixed mainline `vi` environment size parsing to avoid `atoi` overflow UB for large/invalid `LINES`/`COLUMNS` values. Cause: `atoi` on untrusted environment strings invokes undefined behavior on overflow. Fix: use a guarded `strtol` parser that treats invalid/overflowed values as 0 before clamping.
- Hardened mainline `fold` column tracking to avoid size_t wrap on very long lines and replaced `ssize_t` blank indexing with a size_t sentinel to avoid implementation-defined signed overflows; added BSD reference/edge-case documentation.
- Fixed mainline `vi` CRASHME fuzz harness buffer overflows that could write past `readbuffer`/`msg` when generating random commands or diagnostics. Cause: unbounded `strcat` and unchecked index increments into fixed-size buffers. Fix: bounded append helpers that always NUL-terminate and drop excess data.
- Fixed mainline `hexdump` line formatting to guard against `snprintf` errors overflowing the line buffer. Cause: unchecked `snprintf` return values could underflow/overflow `pos` and drive OOB writes on failure. Fix: use bounded append helpers that surface `EOVERFLOW`/`EIO` instead of writing past the buffer.
- Fixed Rust `dd` to avoid size_t truncation on ibs/obs/bs, treat EOF during skip as a normal stop, return non-zero on I/O errors, and handle conv=noerror read errors without infinite retries (zero-pad with conv=sync or advance past the failed block when seekable), matching FreeBSD dd(1) behavior. Cause: unchecked size conversions and missing read-error handling let the applet loop forever or exit 0 on I/O failures. Fix: validate sizes, pad/seek on noerror, and propagate I/O errors via exit status.
- Updated mainline `ps` to use a dynamic `getcwd` buffer and robust stdout writes, avoiding incorrect `<cwd error: ...>` output on long paths and ensuring write failures are reported cleanly.
- Fixed mainline `cp` NULL-destination crash when joining directory targets failed. Cause: `join_path` could return NULL and the code still called `copy_entry`, leading to `open(NULL)`/segfault. Fix: detect `join_path` failures, report the error, and skip the copy.
- Fixed mainline `printf` `%c` handling to treat a lone backslash argument as a literal backslash instead of emitting NUL. Cause: `parse_escape` was called with an empty escape sequence and returned `'\0'`. Fix: short-circuit when the argument ends with `\` to output `\\`, matching BSD printf(1) behavior.
- Fixed mainline `printf` octal escape parsing to accept `\\[0-7]{1,3}` sequences instead of only `\\0...`. Cause: `parse_escape` treated `\\123` as a literal `1`, diverging from BSD printf(1). Fix: parse any leading octal digit and up to two additional digits to produce a byte.
- Fixed mainline `test` unary operator handling to return exit 2 on missing operands (e.g., `test -e`), matching FreeBSD test(1) syntax errors. Cause: single-argument evaluation treated `-e`/`-n`/`-z` as truthy strings. Fix: detect unary operators in the `argc == 1` case and return a syntax error status.
- Fixed mainline `mv` same-file handling to avoid truncation/removal when source and destination resolve to the same inode, and guarded directory-target path joins to avoid NULL destination crashes. Cause: copy+remove path would operate on the same file (truncating it) and `join_path` failure was not checked. Fix: detect identical `st_dev`/`st_ino` pairs and treat as a no-op, plus report and skip when `join_path` fails.
- Fixed mainline `cmp` to reject signed skip offsets so negative inputs don't wrap to huge unsigned skips. Cause: `strtoull` accepts leading `-`, which produced large offsets and incorrect behavior instead of `illegal offset` errors. Fix: reject leading `+`/`-` to match FreeBSD cmp(1) offset parsing.
- Fixed mainline `vi` line-input handling to avoid potential buffer overflows/underflows when copying prompts or processing backspace at the start of input. Cause: unbounded `strcpy` into the status/input buffers and decrement-before-check on erase could underflow if prompt length or call sites change. Fix: bounded prompt copying, safe NUL-termination, and guard backspace before decrementing.
- Fixed mainline `vi` `:set` status rendering to avoid accidental stdout writes and to append `tabstop` safely within the status buffer. Cause: `printf` was called with a pointer to the end of `status_buffer`, producing empty output and bypassing bounds checks. Fix: replace `stpcopy`/`printf` sequence with bounded append helpers so the status line is always NUL-terminated and capped at `STATUS_BUFFER_LEN`.
- Fixed mainline `comm` tab padding to avoid potential out-of-bounds reads if the tab count ever exceeds the fixed literal size. Cause: `write_tabs` passed the requested count to `write_all` using a 2-byte literal buffer. Fix: write tab padding in bounded chunks without relying on a small static buffer.
- Fixed `applets/mainline/user/ulib.c` `atoi` overflow UB by clamping to `INT_MAX` once the decimal accumulator would overflow, preventing signed wrap during pid parsing.
- Fixed mainline `ls`, `mv`, `ln`, `df`, and `du` directory walks to clear `errno` before each `readdir` call so stale errors do not masquerade as directory read failures at end-of-directory.
- Removed a potential data race in `applets/mainline/kill` by eliminating the mutable global signal-name table; signal names are now resolved directly from the static BSD list without shared writable state.
- Updated mainline `du` to report stdout write errors consistently (including per-entry `-a` output) instead of silently ignoring failed `printf` calls.
- Fixed mainline `cd` to print `OLDPWD` only after a successful directory change and to report stdout write errors; added BSD reference comments to match FreeBSD `cd` behavior.
- Hardened mainline `ls` stdout handling by routing formatted output through a bounded `oprintf`/`write_all` path and reporting write failures instead of silently succeeding on EIO/EPIPE.
- Fixed mainline `mv` to reject destinations inside the source tree to avoid recursive self-copy. Cause: directory moves lacked a containment check, allowing `mv src src/subdir` to recurse indefinitely until path or resource limits were hit. Fix: resolve source/destination paths (including non-existent targets) and return `EINVAL` when the destination is a descendant.
- Updated mainline `uname` to use robust stdout writes and report write errors instead of silently succeeding.
- Fixed mainline `env` environment-clearing allocation overflow that could under-allocate and OOB-write when the environment has an extreme entry count. Cause: `calloc(count, sizeof(*names))` without guarding `count * sizeof` overflow. Fix: check `SIZE_MAX` and return `EOVERFLOW` before allocating.
- Hardened mainline `ls`, `sort`, and `vi` string duplication helpers against `size_t` overflow on extremely long strings, avoiding wraparound allocations and potential OOB reads by guarding `strlen + 1`.
- Fixed Rust `cp` destination handling to allow copying a single source to a new path (treating ENOENT as a non-directory), while still rejecting multi-source copies to missing targets. Cause: unconditional `is_dir` error on missing destination. Fix: treat ENOENT as `dest_is_dir = false` and only error for other errno values.
- Fixed mainline `printf` percent conversion handling to avoid UB on invalid length modifiers by rendering `%` with width/flags manually instead of passing an invalid format to `vsnprintf`. Cause: `%` with a length modifier produced `%l%`-style formats, which are undefined in libc. Fix: reject length modifiers and emit the padded percent directly.
- Hardened mainline `cksum` to report `close(2)` failures on input files instead of silently ignoring them, matching other applets' I/O error handling.
- Fixed RISC-V ELF loader crash when running `/bin/init` by forcing contiguous segment loading for PIC binaries so PC-relative PLT/GOT offsets remain valid. Cause: PT_LOAD segments were mapped into separate allocations, so PLT loads read incorrect GOT entries and jumped into unmapped addresses. Fix: prefer `m_elf_load_segment` on RISC-V to preserve the original vaddr layout across text/data.
- Fixed RISC-V ELF argv corruption where applets saw stale or missing arguments because shell argv pointers lived on the caller stack and were overwritten by callee stack usage. Fix: clone argv strings into job heap before entering applet and free after execution.
