# Experimental Go

Experimental Go — дистрибутив, где предпочтение отдается Go-апплетам, а остальное закрывается mainline набором.

## Состав
- Основной набор из `applets/mainline`, кроме тех утилит, у которых есть Go-версии.
- Go-версии заменяют аналоги: `dd`, `hexdump`, `xxd`, а также базовые `echo`, `false`, `pwd`, `sleep`, `true`, `uname`.
- Дополнительно включены Go-апплеты: `goargs`, `gohello`, `gotest`.

## Почему так
- Максимально нагрузить Go-стек на реальных утилитах.
- Посмотреть поведение Go runtime на устройстве.
- Сохранить стандартные имена команд для совместимости.

## Где использовать
- Эксперименты и диагностика Go SDK.
- Демонстрации Go-апплетов.
- Сравнения производительности и размера.

## Где лучше не использовать
- В минимальных или максимально быстрых сборках.
- Если Go toolchain недоступен.
- Для стабильных релизов без тестовых апплетов.

## Сравнение
- Против Mainline: больше Go, тяжелее сборка.
- Против Enhanced: меньше ручной оптимизации, больше демонстрационных апплетов.
- Против Safety: Go присутствует, но цель — эксперименты, а не безопасность.
- Против Nightly: только один вариант каждой утилиты.

## Как собрать
```
python tools/applets.py build --dist experimental-go
```

Также можно задать `MAGNOLIA_DIST=experimental-go`.
