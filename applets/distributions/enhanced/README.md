# Enhanced

Enhanced — сбалансированный дистрибутив: берёт стабильный mainline набор и точечно заменяет ключевые утилиты на «лучшие» реализации.

## Состав
- Основной набор из `applets/mainline`.
- `edit` берётся из Rust (лучше по безопасности и возможностям).
- `dd`, `hexdump`, `xxd` берутся из Zig (компактные и быстрые).
- Демо/тестовые апплеты исключены.

## Почему так
- Дать «оптимум по умолчанию» без лишних экспериментальных утилит.
- Использовать сильные стороны каждого языка.
- Сохранить совместимость команд при разумном размере.

## Где использовать
- Ежедневные сборки и повседневная работа.
- Когда нужен баланс скорости, размера и безопасности.
- Когда важно избежать лишних тестовых апплетов.

## Где лучше не использовать
- Если нужен полностью чистый C (выбирайте Mainline).
- Если нужна максимальная безопасность (выбирайте Safety).
- Если нужно всё сразу для сравнения (выбирайте Nightly).

## Сравнение
- Против Mainline: больше оптимизации, но больше зависимостей.
- Против Experimental *: меньше экспериментов, больше практичности.
- Против Safety: меньше упор на безопасность памяти.
- Против Nightly: меньше размер и хаос.

## Как собрать
```
python tools/applets.py build --dist enhanced
```

Также можно задать `MAGNOLIA_DIST=enhanced`.
