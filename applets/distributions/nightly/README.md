# Nightly

Nightly — дистрибутив, в котором включены вообще все апплеты. Дубликаты получают уникальные имена по языковому префиксу.

## Состав
- Все апплеты из `applets/mainline`, `applets/rust`, `applets/zig`, `applets/go`.
- Для конфликтующих имён используются префиксы, например:
  - `dd`, `rdd`, `zdd`, `godd`
  - `hexdump`, `rhexdump`, `zhexdump`, `gohexdump`
  - `echo`, `goecho`

## Почему так
- Максимальная полнота для сравнения и отладки.
- Можно параллельно проверять разные реализации одной утилиты.
- Удобно для nightly/CI прогонов и диагностики.

## Где использовать
- Исследования, сравнения, тесты.
- Поиск регрессий между реализациями.
- Разработка SDK и интеграций.

## Где лучше не использовать
- В продакшн-сборках.
- На устройствах с жестким лимитом памяти.
- Когда нужна минимальная и предсказуемая поставка.

## Сравнение
- Против всех остальных: максимум функций, но максимум размера и шума.
- Полезен для разработчиков, но не для конечных релизов.

## Как собрать
```
python tools/applets.py build --dist nightly
```

Также можно задать `MAGNOLIA_DIST=nightly`.
