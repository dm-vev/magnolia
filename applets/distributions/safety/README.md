# Safety

Safety — дистрибутив с акцентом на безопасные по памяти реализации. Где возможно, используются Rust/Go апплеты вместо C.

## Состав
- Базовый набор из `applets/mainline`.
- Rust-версии заменяют `dd`, `hexdump`, `xxd`.
- Rust `edit` вместо C-редактора.
- Go-версии заменяют `echo`, `false`, `pwd`, `sleep`, `true`, `uname`.
- Демо/тестовые апплеты исключены.

## Почему так
- Снизить риск ошибок памяти в наиболее чувствительных утилитах.
- Оставить mainline там, где альтернатив нет.
- Сохранить стандартные имена команд.

## Где использовать
- Сборки с повышенными требованиями к безопасности.
- Демонстрации безопасных апплетов.
- Сценарии, где важнее надежность, чем размер.

## Где лучше не использовать
- На сильно ограниченной флеш-памяти.
- Когда важна максимально быстрая сборка.
- Если не готовы тянуть Rust/Go toolchain.

## Сравнение
- Против Mainline: безопаснее, но тяжелее.
- Против Enhanced: больше упор на безопасность, меньше балансировки.
- Против Experimental *: меньше экспериментов, больше практичности.
- Против Nightly: значительно меньше размер и риски.

## Как собрать
```
python tools/applets.py build --dist safety
```

Также можно задать `MAGNOLIA_DIST=safety`.
