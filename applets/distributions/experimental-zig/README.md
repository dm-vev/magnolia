# Experimental Zig

Experimental Zig — дистрибутив, где предпочтение отдается Zig-апплетам, а остальной набор берется из mainline.

## Состав
- Все основное из `applets/mainline`.
- Zig-версии заменяют аналоги: `dd`, `hexdump`, `xxd`.
- Дополнительно включены Zig-апплеты: `zigdemo`, `zighello`, `zigtest`.

## Почему так
- Протестировать Zig-стек на реальных утилитах.
- Получить быстрые и компактные реализации для байтовых инструментов.
- Сохранить привычные имена команд.

## Где использовать
- Эксперименты с Zig и сравнительные бенчмарки.
- Демонстрации возможностей Zig SDK.
- Быстрые проверки поведения Zig-апплетов.

## Где лучше не использовать
- В минимальных прошивках, где важен размер и стабильность.
- Когда нужен строгий фокус на безопасность памяти.
- Для релизов без тестового шума.

## Сравнение
- Против Mainline: больше Zig, выше экспериментальность.
- Против Enhanced: меньше ручного отбора, больше демонстрационных апплетов.
- Против Safety: фокус на Zig, а не на безопасность.
- Против Nightly: только одна реализация каждой утилиты.

## Как собрать
```
python tools/applets.py build --dist experimental-zig
```

Также можно задать `MAGNOLIA_DIST=experimental-zig`.
