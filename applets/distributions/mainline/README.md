# Mainline

Mainline — базовый набор апплетов Magnolia на чистом C. Это эталонная, максимально предсказуемая поставка без экспериментальных языков.

## Состав
- Все апплеты из `applets/mainline`, включая `dd`, `hexdump`, `xxd`.
- Без Rust/Zig/Go реализаций.

## Почему так
- Минимальные зависимости и быстрый билд.
- Наиболее стабильные и привычные реализации.
- Удобная отправная точка для сравнения других дистрибутивов.

## Где использовать
- Базовые и стабильные сборки.
- Минимальные прошивки, где важны размер и предсказуемость.
- CI и регрессионные тесты базовой функциональности.

## Где лучше не использовать
- Когда нужна повышенная безопасность памяти.
- Когда нужно сравнить реализации на разных языках.
- Когда важна демонстрация Rust/Zig/Go стека.

## Сравнение
- Против Experimental *: меньше экспериментов, больше стабильности.
- Против Enhanced: проще, но без подборки «лучших» реализаций.
- Против Safety: меньше упора на безопасные языки.
- Против Nightly: значительно меньше размер и риски.

## Как собрать
```
python tools/applets.py build --dist mainline
```

Также можно задать `MAGNOLIA_DIST=mainline`.
