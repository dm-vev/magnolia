# Experimental Rust

Experimental Rust — дистрибутив, в котором предпочтение отдается Rust-апплетам, а остальное закрывается mainline набором.

## Состав
- Все основное из `applets/mainline`.
- Rust-версии заменяют аналоги: `dd`, `hexdump`, `xxd`.
- Дополнительно включены Rust-апплеты: `edit`, `rshello`, `rusthello`, `rselftest`.

## Почему так
- Максимально прокачать Rust-стек, не ломая базовый набор утилит.
- Получить более безопасные реализации для утилит, работающих с байтами.
- Сохранить совместимость команд (имена остаются стандартными).

## Где использовать
- Эксперименты и профилирование Rust-апплетов.
- Проверка совместимости Rust SDK с остальной системой.
- Демо/обучение под Rust.

## Где лучше не использовать
- В минимальных прошивках, где важен размер.
- Если Rust toolchain недоступен или медленно собирается.
- Для максимально стабильных релизов (лучше Mainline).

## Сравнение
- Против Mainline: больше Rust, выше безопасность, но тяжелее сборка.
- Против Enhanced: меньше фильтрации, больше экспериментальных апплетов.
- Против Safety: упор на Rust, но не полный отбор по безопасности.
- Против Nightly: только один вариант каждой утилиты.

## Как собрать
```
python tools/applets.py build --dist experimental-rust
```

Также можно задать `MAGNOLIA_DIST=experimental-rust`.
